# /distill —— 知识沉淀

把刚刚发生的这场对话，提炼成会留下来、会复利的知识资产。你不是在做会议记录，而是在帮用户把「想过的东西」变成「拥有的东西」。

知识库根目录：`E:\aiproject\doctor\knowledge\`

## 心法

- **抽精华，不抄全文**。只留下值得三个月后还想看的东西。一次对话可能只产出 1 张卡片，也可能 0 张——宁缺毋滥。
- **中文为主，英文埋点**。卡片正文中文，但每张卡片标一个相关的英文术语，帮用户顺手学英语（用户是中级学习者）。
- **观察人，不只是记事**。除了「聊了什么」，更要注意「用户是怎么想的」——这才是成为人生导师的根基。
- **真诚**。这是用户托付给你的「第二大脑」，用对待挚友笔记的认真程度来写。

## 执行步骤

### 1. 回看本次对话
通读当前 conversation，识别：值得留存的认知、用户展现的思考方式、暴露的知识缺口、出现的英文术语。如果这次对话纯粹是操作性的（没有认知含量），如实告诉用户「这次没什么特别要沉淀的」，不要硬凑。

### 2. 写认知卡片 → `cards/YYYY-MM-DD-主题.md`
每条值得留存的认知写一张卡片，格式见 `cards/README.md`：
```markdown
## [标题] · YYYY-MM-DD

**主题**：#标签 #标签
**英文术语**：term (中文释义)

**核心**：一两句话。

**为什么重要 / 触发场景**：用户当时的困惑或目标。

**延伸**：可深挖方向 → [[关联卡片或gap]]
```
同一天多张卡片可放同一文件追加，或分文件加序号。

### 3. 增量更新思考模式画像 → `thinking-style/profile.md`
读现有 profile，只在观察到**新的或更清晰的**模式时追加/修订。更新「最近更新」日期。关注：用户偏好的推理路径、提问习惯、决策风格、优势、可能的盲区。盲区要温和、对事不对人。证据不足就不要写——画像要准，不要编。

### 4. 登记知识缺口 → `gaps/open-questions.md`
对话中暴露的「还没想透/还没补上」的点，追加到「待解决」区：
```
- [ ] [缺口] 描述 · 来源：YYYY-MM-DD · 建议方向：xxx
```
如果这次对话解决了某个旧缺口，把它标 `[x]` 并移到归档区。

### 5. 积累英文术语 → `english/vocab.md`
把对话中出现的、值得记的英文术语/短语追加进表格（1-5 个即可，挑用户水平往上够一够的）。已存在的不重复。

### 6. 更新总索引 → `INDEX.md`
更新概览里的计数、「最近一次沉淀」日期；如果出现新主题，加到「主题地图」并链接到卡片。

### 7. 同步到 Claude memory
把**关于用户本人**的稳定洞察（思考模式、长期兴趣、价值观）按 memory 规范写入 `E:\ClaudeConfig\projects\E--aiproject-doctor\memory\`（user 或 feedback 类型）。注意：易变的项目细节、能从知识库文件读到的内容**不要**重复进 memory——memory 只存「跨对话、关于这个人」的精华。

### 8. 向用户汇报
简短汇报：写了几张卡片、画像有无更新、新增几个缺口、学了哪几个英文词。最后用一句挚友式的话收尾——点出这次对话里你觉得最有价值或最值得他自己注意的一点。然后提醒：想要方向指引和书单时输入 `/mentor`。

## 注意
- 所有相对日期换成绝对日期（今天是对话发生的实际日期）。
- 文件已存在就用 Edit 追加/修订，不要覆盖历史。
- 写完不需要逐字读回验证。
